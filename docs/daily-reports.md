# 家友日报生成与重新生成

日报窗口为北京时间前一天08:00至当日08:00，左闭右开。候选取精选、原漏选补充、窗口内曾进入公开热点榜的事件及雷达A类文章。所有路径汇总后统一历史排重，按现有事实归组汇成事件，沿用评分、独立参与方、权威加分及跟进扣分排序。

排序后每批最多6个事件（含相关进展的文章摘要）调用report模型进行日报适用性判断；逐篇记录include、exclude、needs_body及引用证据。需要正文时只读取已有的已确认正文，正文缺失或结果无法完成判断时本期生成失败，保留原刊供管理员处理，不将未知当无关或直接放行。主条目、快讯及附带报道都须通过。凑够12个主条目、10条快讯后停止，主条目同一来源最多2条；候选耗尽不凑数。方法、资源、观点等跟进稿不再受权威或4来源门槛。

## 展示与API

日报详情、快讯、相关报道及头条显示该文章自身的“精选”、该事件本窗口的“热点”，以及文章AI评分；标签可叠加。本期雷达A类关联文章同时显示“热文雷达”标签。评分缺失显示暂无评分。

GET /api/v1/dailies/latest 与 GET /api/v1/dailies/:date 的文章对象返回：

| 字段 | 含义 |
|---|---|
| itemId | 文章ID；旧记录缺失为null |
| selected | 生成时该文章是否精选；未知为null |
| hot | 事件是否在本期窗口曾上榜；未知为null |
| fromRadar | 是否由本期热文雷达A类记录提供；新刊true/false，旧刊未记录为null |
| score | 文章生成时的综合分；未知为null |
| related | 可公开的相关报道，含各自ID与以上状态，不继承主稿精选或分数 |

report.lead同样返回itemId与状态字段；无文章可关联的安静日报字段为null。历史快照不会随当前评分漂移，明确重新生成才更新；撤回等公开范围限制继续实时执行。

## 手动重新生成

所有访客可以使用日报底部灰色“重新生成”按钮。公开POST /api/site/reports/daily/:date/regenerate返回run；GET /api/site/reports/daily/:date/regeneration返回最近队列状态，具体限制见下节。点击只排队，付费审核在worker执行；同一期并发请求复用待执行任务，定时／手动生成通过会话锁互斥。

重新生成不重跑文章预筛、五维评分、分类或标题摘要，仍使用原期窗口。成功替换并保留旧版本，记录操作人和原因；失败保留旧日报并提示管理员。自动任务只补缺失期，不覆盖已有日报。

## 热文雷达候选

雷达模块通过dailyCandidates钩子返回本期历史快照中的A类站内文章及来源、时间、排名，日报引擎再次检查公开资格后汇入候选。时间取前一天08:00至当天08:00内的快照采集时间，不只读最新榜单。只有已确认正文、可用摘要及有效公开文章可补入，不要求精选；B/C、未完成判断、正文未就绪、隔离及撤回记录不补入。先使用正文任务关联，旧快照无关联时只允许唯一精确原文URL匹配。历史排重和事件合并仍在所有候选汇总后统一执行；接入不会触发新采集、重新评分或修改雷达判定。

## 公开重新生成入口调整

日报底部“重新生成”向所有访客开放，不需要账号。网页使用/api/site/reports/daily/:date/regenerate提交，以及同路径的/regeneration读取状态，均不缓存；写请求要求x-daily-regeneration: 1并拒绝跨站浏览器请求。同一期在排队或运行期间重复提交合并为一个任务，模型调用继续经过worker、回执与预算控制。已有管理员接口保留原权限，其他后台不开放。

## 日报 Markdown 与提示词管理

日报详情底部可下载当前期 Markdown，包含日报链接、各栏目及相关报道的标题、摘要、站内链接、原文链接、精选、热点、雷达及 AI 评分。文章标签和主题取当前公开元数据，历史日报未记录的状态显示为未知。

后台「设置 → 提示词管理」仅管理日报适用性审核。下载生效版本，在本地编辑后上传预览，再确认发布。可从最近 20 个历史版本选取内容重新发布。未发布过后台版本时使用部署内的 daily-review.md。发布后每次新生成固定使用启动时读取的版本，已生成日报需重新生成才会应用。后台发布后，仓库模板更新不会覆盖后台生效版本。

### 润思接入日报 Markdown

`GET /api/v1/dailies/{date}/markdown` 按北京时间日报日期返回网页下载的同一份内容。无需登录，读取 UTF-8 Markdown 响应正文即可。缓存过期后可传 `If-None-Match`，未变化返回 304。无效日期返回 400，未出刊返回 404。
