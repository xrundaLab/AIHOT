# EduHOT V1.2.2 主题标签

本目录保存结构化链路使用的 V1.2.2 词表和提示词。`standard.json` 按交接工作簿 01–04 表导出：13 个主题、52 个匹配标签、40 个细标签、7 类资料。工作簿 SHA-256：`3b21ca1af96608ea71df42487b429c6f367b21545f981d15f8945c46ada5e33c`。

`prompt.ts` 展开提示词，`evidence.ts` 校验引文在原文和模型可见输入中均存在。结构化分析将版本、正文状态、两类标签及证据写入 `analyses.output.structureV122`；公开标签只使用细标签，主题只由匹配标签映射。`mapping.ts` 可用于比较全部主题与旧三标签上限的差异。E1 仅供后台编辑案例检索，不列入公开主题。

旧分析无新版版本标记，继续按旧词表归属，旧主题链接仍可访问。仅重评的文章使用新版。回退代码会恢复旧提示词与目录，但新版分析中的细标签不一定能恢复为旧版主题标签；需要重新评估才能重新生成旧版归属。真实模型试跑仍需锁定完整正文及独立业务预期，并保存请求、原始响应和模型信息。
